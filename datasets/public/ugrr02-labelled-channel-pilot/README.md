# UGRR02 labelled channel pilot

One controlled labelled absolute window with 6 STILL/MOVE cycles at one channel
state. The bundle retains only aggregate sensing, service, QC, and alignment
values. `deployment.md` records only anonymized relative placement roles.
`scripts/build_ugrr_labelled_segment.py` recreates the data file.

This is not a paired action effect, canonical P1 table, or model dataset.
