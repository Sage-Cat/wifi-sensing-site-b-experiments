# Abstract deployment

The pilot used five fixed relative roles with no published coordinates:

`zone-Z01` near-end managed radio and controller;
`zone-Z02` mid-zone sensing receiver and collector;
`zone-Z03` boundary protected-service client;
`zone-Z04` adjacent-zone managed radio; and
`zone-Z05` far-end sensing receiver and collector.

The mid-zone receiver observed the adjacent-zone radio path, while the far-end
receiver observed the near-end radio path. This relative layout supplies two
spatially distinct sensing views. It was fixed for the pilot but not randomized
or replicated across sites, so it supports topology description only.

Exact geometry, photographs, equipment identities, and environmental details
are excluded.
