# Public data dictionary

There are no published datasets. Future metadata may describe only approved,
aggregate variables using the dataset metadata schema. A bundle records an
`MSBnn` program, abstract site/level/zone aliases, relative or coarsened time,
one bounded evidence status, a privacy-review record, and an explicit claim
boundary. The manifest uses only an opaque `SRC-XXXXXXXXXXXX` source record;
private paths and private campaign names never cross into this repository.

Definitions must avoid direct identifiers, exact times, detailed spatial
attributes, network/device identifiers, and natural-occupancy ground truth.
