# MSB protocol (prospective)

This protocol is a planning baseline, not evidence of execution. MSB00 must
complete governance and privacy review before collection. MSB01 then evaluates
research sensing equipment in an instrument-only setting. MSB02 may proceed
only under documented controls and consent, using abstract `site-S01`,
`level-Lxx`, and `zone-Zxx` labels. MSB03 uses a pre-registered held-out
comparison across abstract levels; MSB04 assesses planned temporal robustness.

Collection and analysis must minimize data at source. Private operational
evidence remains outside this repository. Use aggregate, non-identifying
features; prohibit raw captures, direct identifiers, network identifiers,
absolute schedules, media, floorplans, and location coordinates. Natural
occupancy is not ground truth for a person or occupancy state.

For each stage, record internal approval, versioned analysis definitions,
quality results, exclusions, and abort decision. Only a separately reviewed,
manifest-approved sanitized bundle may cross to the public repository.
